## What Is SaQle

Saqle is a modular, component based, MVC framework for rapid prototyping.

It is batteries included, easy to pick up by anyone from beginner to expert level PHP developers.

SaQle is built to help get you from idea to prototype/POC in hours instead of days while 
giving you a solid foundation to build a complex and secure application on.

Feature Overview

1. A simple, fully functional and customizable ORM for database interaction
2. Component first MVC architecture for ease of re-use
3. Request dispatcher with clean, custom URLs and routes
4. Built-in model and forms validation
5. Simple but powerful templating engine
6. Cookies, security, session, and request handling management components
7. Customizable and extendable authorization and authentication
8. Out of the box multitenancy support
9. Out of the box image/video uploads, resizing and cropping
10. Out of the box administrator panel
11. Many more features....


## Why SaQle

I come from an intense background of building customer facing applications, where half baked change requests come so often that before you finish a feature you are throwing it out of the window to start another.

Having worked with C# Entity Framework, Python's Django and FastApi, PhP's Laravel and Cake, I wanted to see if I could build my own custom framework, one that could support rapid protoyping and delivery in a fast paced environment.

Therefore, more than anything else, this is a fun personal project, that has made me learn lots of good
software engineering techniques, but which I hope will be as useful to you as it has been in my freelance
projects.
