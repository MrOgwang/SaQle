# Project Structure

A SaQle project is structured as shown:

- MyProject
	- Config
	- Env
		- Development
		- Production
	- Public
	- Src
		- Bootstrap
		- Components
		- Databases
			- Migrations
			- Schemas
			- Snapshots
		- Modules
			- Auth (Example module)
				- Components
				- Contracts
				- Data
					- Seeders
				- Listeners
				- Events
				- Middleware
				- Models
				- Notifications
				- Routes
				- Services
				- Validators
	- Storage
	- Vendor
