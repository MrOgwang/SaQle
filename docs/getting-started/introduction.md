# Getting Started

## Introduction

The best way to learn SaQle will be to jump right in and build an end to end application with it. Fear not, I will guide you through this process in a simple, step by step manner. 

We will build a simple task tracker application with the following core functionality:

- Users can register and log in.
- Users can create tasks.
- Users can view their tasks.
- Users can edit and delete tasks.
- Users can mark tasks as completed.
- Users can filter tasks by status.
- Users can access their tasks through both a web interface and an API.
